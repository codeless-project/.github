## our current models  
### boolean  
boolean is our text generation model that can generate either Yes/No/Probably/Probably Not/I don't know/What.  
it's latest version is currently boolean 1.5.  
### flude  
flude is our mood detecting model that generates a number from 1-64. it's mood system is based on a mood grid. it starts from the top left, and ends at the bottom right.  
<img src="https://raw.githubusercontent.com/codeless-project/.github/refs/heads/main/profile/mood_grid.png"></img>  
it's latest version is currently flude 1.5.
